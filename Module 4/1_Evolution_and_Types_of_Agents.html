Section 01

What Is an Agent?

The classical definition (Russell & Norvig): an agent is anything that perceives its environment through sensors and acts upon that environment through actuators. The definition is deliberately broad. A thermostat, a chess program, a robot vacuum and an LLM calling tools are all agents. They differ only in what happens inside the "decide" step.

FIG 1 — The universal agent loop: perceive the environment via sensors, decide via some internal function, act via actuators, and the environment changes — feeding new percepts back in. Everything in this module is a different answer to "what happens inside the box?"

ThermostatCurrent temperatureHeater on / offOne fixed rule
Chess programBoard positionMove a pieceSearch over future moves
Robot vacuumBump and cliff sensorsWheels, brushesLayered reflexes

Keep this one question in mind for the whole module: what happens inside the box? Section 02 shows how the answer changed over 70 years. Section 03 gives the standard names for the answers.
Section 02

The Historical Evolution of Agents

"Agent" is not a new word in AI. Each era found a new way to fill the decision box, and each left behind an agent type we still use. Read the timeline as a story: rules → search → reflexes → commitments → learning → language.

FIG 2 — The six eras. The structure around the decision (goals, actions, state, search) has barely changed; the decision-maker has.

What's actually new about LLM agents: not the concept of an agent, but the reasoning engine at its centre. Classical planners needed a hand-built symbolic model of the world. LLM agents reason in natural language and can be pointed at open-ended tasks without anyone writing the state space first. What's reused, largely unchanged, is the structure around it: goals, actions, state and search (Part 2), and tools as actions (Part 3).
Section 03

The Five Agent Types (Russell & Norvig)

This is the taxonomy of agent types. Everything else in this Part (reactive, deliberative, BDI, rational) is a way of grouping or judging these five, not a separate list. Each type adds one capability to the one before, so the list is drawn as a ladder.

1

Simple reflex

Acts on the current percept only, using condition → action rules.

2

Model-based reflex

+ internal state: remembers what it can't currently see.

3

Goal-based

+ goal: predicts outcomes and picks actions that reach it.

4

Utility-based

+ utility: picks the best way to reach the goal, not just any way.

5

Learning

+ improvement: any of types 1–4 that gets better from experience.

// The agent program for each type 1. Simple reflex action = rules[ interpret(percept) ] 2. Model-based state = update(state, last_action, percept) action = rules[ state ] 3. Goal-based action = first step of a plan whose result satisfies the goal // HOW it plans: Part 2 4. Utility-based action = argmax_a E[ U( result(state, a) ) ] 5. Learning critic scores behaviour → learning element updates the rules / model / utility

One running example: an automated taxi

TypeWhat the taxi doesWhat it can't do (and why the next rung exists)
1. Simple reflexif car_in_front_is_braking → brakeChange lanes safely: a car in the blind spot isn't in the current percept
2. Model-based reflexRemembers "a car went into my blind spot 2 seconds ago" and waitsDecide which way to turn: rules alone don't know where the passenger is going
3. Goal-basedGoal = At(Airport). Predicts where each turn leads and picks a route that gets thereTell a 20-minute route from a 2-hour route: both reach the goal, and a goal is just yes or no
4. Utility-basedScores routes by U = speed + safety + comfort − fuel cost and picks the highestImprove itself: its rules and weights stay fixed
5. LearningLow tips after hard braking → the critic flags it → the braking rule is softened(No new limit: learning can be added to any rung)
Exam favourite: goal-based vs. utility-based. A goal is binary: At(Airport) is true or false. A utility is a number that ranks outcomes, so the agent can compare "arrived quickly and safely" with "arrived late after a near-miss". Utility also handles conflicting goals (speed vs. safety) and uncertainty (90% chance of a fast route vs. a guaranteed slow one) by maximising expected utility.

How do we judge any of these? Rationality

The ladder says how an agent is built. Rationality says whether it acts well. A rational agent chooses, for whatever it has perceived so far, the action expected to maximise its performance measure. The utility-based agent (rung 4) is simply this definition turned into a program.

Rational action = argmax_action E[ Performance | percept sequence, prior knowledge, action ] // Relative to FOUR things — change any one and the "rational" action changes: // 1. performance measure 2. percept sequence so far 3. prior knowledge 4. available actions
Real-world example: a streaming service's recommender. Performance measure = expected watch time; percepts = your watch history and clicks; prior knowledge = what millions of other viewers watched; actions = which titles to show. It isn't guaranteed to pick a film you'll love. It is rational in the formal sense: the best choice given exactly that information. Rational ≠ always right.
Section 04

Reactive vs. Deliberative: Two Halves of the Same Ladder

"Reactive" and "deliberative" are not new agent types. They split the ladder from Section 03 into two families, by one question: does the agent think ahead before acting?

FIG 3 — Rungs 1–2 react to what they perceive; rungs 3–4 reason over a model of the world and look ahead. Learning cuts across both.
Reactive (rungs 1–2)Deliberative (rungs 3–4)
Decides byMatching rules to the current percept (plus a little memory)Reasoning or search over an internal model of the world
SpeedVery fastSlower: reasoning costs time
Novel situationsPoor: only what the rules anticipatedBetter: can reason about situations never seen before
Failure modeNo fallback when the rules don't cover the caseA wrong or stale world model leads to wrong plans
Classic exampleEarly iRobot Roomba: drive, bump, turn. Brooks' subsumption architecture layers reflexes, with higher layers overriding lower onesGPS navigation: builds a route over a road graph, and re-plans from scratch when you miss a turn
Most real systems are hybrid. A self-driving car brakes reflexively for an obstacle (reactive, for safety) while planning its route deliberatively (for efficiency). LLM agents do the same: answer simple requests directly, and switch to step-by-step reasoning and planning for hard ones.

BDI: how a deliberative agent is organised inside

Deliberative agents need a structure for "what I know, what I want, and what I'm doing about it". The most influential one is BDI (Bratman, 1987; Rao & Georgeff, 1995). It is an architecture for rungs 3–4, not a sixth type.

B

Beliefs

The agent's model of the world. May be incomplete or wrong; updated by new percepts.

D

Desires

Goals it would like to achieve. Can be many, and can conflict.

I

Intentions

The desires it has committed to, each with a concrete plan it is now executing.

Real-world example: NASA's Remote Agent flew the Deep Space 1 probe in 1999. Beliefs: the spacecraft's state from telemetry. Desires: mission goals such as an asteroid fly-by. Intentions: the committed sequence of thruster burns it was executing, re-planned only when beliefs changed enough. The same "commit to a plan, re-plan only on failure" idea returns in Part 2 as the plan-and-execute strategy for LLM agents.

Section 06

Key Takeaways & Exam Prep

✓

Agent = perceive + decide + act

A thermostat and an LLM tool-caller both qualify; only the decision box differs.

✓

Six eras, one loop

Rules → search → expert systems → reactive/BDI → learning → LLMs.

✓

One taxonomy: the five-rung ladder

Simple reflex → model-based → goal-based → utility-based, with learning on top.

✓

Reactive / deliberative = two halves

Rungs 1–2 react; rungs 3–4 look ahead. BDI organises the deliberative half.

✓

Rational ≠ always right

Best expected action given the information available.

Common exam questions

QuestionShort answer
Name the five Russell & Norvig agent types and what each adds.Simple reflex (current percept) → model-based (+ internal state) → goal-based (+ goal and lookahead) → utility-based (+ a score to choose the best outcome) → learning (+ improvement, applicable to any type)
How do "reactive" and "deliberative" relate to the five types?They are two families of the same ladder: reactive = simple and model-based reflex (no lookahead); deliberative = goal- and utility-based (reason over a world model before acting)
Why is a utility-based agent more general than a goal-based one?A goal is binary; utility ranks outcomes, so the agent can trade off conflicting goals and handle uncertainty by maximising expected utility
What four things is rationality relative to? Is a rational agent always successful?Performance measure, percept sequence, prior knowledge, available actions. No: rationality is the best expected decision given the information, not omniscience
In BDI, why are desires and intentions separate?Desires are candidate goals and may conflict; intentions are the committed subset being acted on, which stops endless reconsideration
What is genuinely new about LLM agents compared with classical agents?The decision-maker: natural-language reasoning that works on open-ended tasks without a hand-built state space. Goals, actions, state and search are inherited
