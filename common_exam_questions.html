Module 1

Neural networks, attention, LLMs and fine-tuning
Derive one step of forward propagation in a neural network.

Core derivationDefine the weighted sum z = Wx + b, apply the activation a = f(z), and identify the dimensions of W, x, b and a. Explain how the calculation repeats layer by layer.

Why are activation functions necessary? Compare sigmoid, tanh and ReLU.

CompareWithout a nonlinear activation, stacked layers collapse into one linear transformation. Compare output range, saturation, gradient behavior and the practical use of each function.

Explain backpropagation and the chain rule.

Core derivationStart from the loss, propagate gradients backward through each operation using the chain rule, and update parameters with gradient descent: theta := theta - learning_rate times gradient.

What causes vanishing and exploding gradients in RNNs?

ExplainRepeated multiplication by recurrent Jacobians makes gradients shrink or grow exponentially over many time steps. Relate this to long-term dependencies and explain how LSTM/GRU gates, clipping and initialization help.

Compare an RNN, LSTM and GRU.

CompareDiscuss recurrence, memory path, gates, parameter count, long-range memory and computational cost. LSTMs use separate cell and hidden states; GRUs combine them with fewer gates.

What problem does attention solve in encoder-decoder models?

High yieldA fixed context vector bottlenecks long inputs. Attention creates a context vector per decoder step by weighting encoder states according to relevance.

Explain the four steps of additive or dot-product attention.

Core derivationCompute compatibility scores, normalize them with softmax, use the weights to form a weighted sum of values, and pass the resulting context to the decoder.

What are Query, Key and Value vectors?

High yieldQueries express what the current token is looking for, keys describe what each token offers for matching, and values contain the information blended into the output.

Why is scaled dot-product attention divided by square root of d_k?

Exam favouriteDot products grow in magnitude as key dimension grows, saturating softmax and producing tiny gradients. Scaling keeps score variance controlled.

Distinguish self-attention from cross-attention.

CompareSelf-attention obtains Q, K and V from the same sequence. Cross-attention obtains queries from one sequence and keys/values from another, as in decoder-to-encoder attention.

Why does a Transformer need positional information?

ExplainAttention alone is permutation-equivariant and does not know token order. Positional encodings or RoPE inject relative or absolute position information.

Explain multi-head attention and its advantage.

High yieldSeveral smaller attention operations learn different relationship types in parallel, then concatenate and project their outputs. This gives the model multiple representation subspaces.

What is causal masking and why is it required for decoder-only LLMs?

ExplainEach position may attend only to itself and earlier positions. The mask prevents seeing future target tokens during training, preserving the next-token prediction objective.

Compare encoder-only, decoder-only and encoder-decoder Transformers.

CompareEncoder-only models are strong for representation and classification, decoder-only models generate autoregressively, and encoder-decoder models map an input sequence to an output sequence.

Explain BPE tokenization and its trade-offs.

ExplainBPE repeatedly merges frequent symbol pairs. It balances vocabulary size and sequence length, but token boundaries can be unintuitive and rare words may split into many tokens.

What is perplexity and what does it measure?

DefinitionPerplexity is the exponentiated average negative log-likelihood. Lower perplexity means the model assigns higher probability to the observed sequence, though it is not a complete measure of usefulness.

Why do modern LLMs use RoPE?

Exam favouriteRoPE rotates query and key pairs by position so their dot product encodes relative distance. It supports useful extrapolation and integrates position directly into attention.

Why does KV-cache memory grow with conversation length?

Exam favouriteInference stores keys and values for every previous token in every layer. Each new token reuses them, but the stored sequence grows linearly with context length.

Compare temperature, top-k and top-p decoding.

CompareTemperature reshapes the whole probability distribution, top-k keeps a fixed number of candidates, and top-p keeps the smallest adaptive set whose cumulative probability reaches p.

Why does temperature 0 not eliminate hallucinations?

Exam favouriteIt makes decoding more deterministic but does not add knowledge or grounding. A confidently selected token can still be unsupported or wrong.

Compare in-context learning, full fine-tuning and PEFT.

CompareICL changes only the prompt at inference; full fine-tuning updates all weights; PEFT updates a small set of added or selected parameters while preserving most base weights.

Why is full fine-tuning expensive?

ExplainTraining requires gradients and optimizer states in addition to weights. Memory, compute, data requirements and catastrophic forgetting all increase with model size.

Explain LoRA and derive its trainable parameter count.

Core derivationReplace an update delta-W with B A, where the rank r is small. For a d-out by d-in weight, trainable parameters are r(d-in + d-out), far fewer than d-in d-out.

Why is B initialized to zero and A randomly?

Exam favouriteB A starts as zero, so the adapted model initially matches the base model. Both-zero initialization would block useful gradients, while both-random would immediately disturb pretrained behavior.

What is quantization and what are its risks?

ExplainQuantization maps higher-precision values to fewer bits using a scale and often a zero-point. It reduces memory and can speed inference, but may introduce accuracy loss and calibration sensitivity.

Module 2

Prompting, reasoning, scaling and structured outputs
Compare zero-shot and few-shot prompting.

CompareZero-shot gives instructions without examples; few-shot includes input-output demonstrations. Few-shot helps with format and edge cases but costs context and can introduce misleading patterns.

Why does few-shot performance eventually stop improving?

Exam favouriteMore examples can dilute the query, introduce noise or bias, consume context window space and increase sensitivity to ordering and recency.

What is chain-of-thought prompting and when is it useful?

ExplainIt elicits intermediate reasoning steps, improving many multi-step arithmetic, logic and planning tasks. It costs more tokens and should be evaluated for correctness rather than trusted automatically.

How does self-consistency improve chain-of-thought?

ExplainSample multiple reasoning paths, extract their final answers and select the majority answer. It works when independent errors are diverse, but increases inference cost.

What does Tree-of-Thoughts add beyond self-consistency?

Exam favouriteSelf-consistency samples complete paths independently. ToT maintains partial states, evaluates them, and deliberately expands, prunes or backtracks through a search tree.

Compare Tree-of-Thoughts, Graph-of-Thoughts and ReAct.

CompareToT searches branching states, GoT permits arbitrary graph connections and aggregation, while ReAct interleaves reasoning with actions and observations from tools or an environment.

What is test-time scaling?

DefinitionAllocate additional computation during inference rather than only increasing training compute, using more samples, longer deliberation, verification or search to improve answers.

Does majority voting always improve accuracy as sample count increases?

Exam favouriteNo. It helps when errors are sufficiently independent and the correct answer is more probable, but correlated reasoning errors and weak answer distributions can limit or reverse gains.

What makes a prompt reliable and reproducible?

PracticalSpecify the task, context, constraints, output format, evaluation criteria and edge cases. Use consistent delimiters, examples where useful, and separate untrusted data from instructions.

Why use structured generation instead of asking for JSON?

ExplainPlain instructions do not guarantee valid syntax or schema compliance. Constrained decoding, schemas, validators and retries make outputs machine-readable and operationally reliable.

Explain tool calling or function calling.

DefinitionThe model emits a structured tool name and arguments matching a declared schema. The application validates and executes the tool, then returns the result to the model or user.

What is DSPy and how does it differ from hand-written prompts?

ExplainDSPy represents prompting as typed signatures and programs, then optimizes instructions and demonstrations against a metric rather than relying only on manual wording.

Module 3

Retrieval-augmented generation
Explain the RAG pipeline from documents to answer.

Core workflowIngest and clean documents, chunk them, embed and index chunks, retrieve candidates for a query, optionally re-rank, place selected context in the prompt, generate, and evaluate the answer.

What is cosine similarity and why is it used for embeddings?

Core derivationCosine similarity is the dot product divided by the product of vector magnitudes. It compares direction while reducing sensitivity to vector length, making it useful for semantic matching.

Compare dense, sparse and hybrid retrieval.

CompareDense retrieval captures semantic similarity, sparse methods such as BM25 preserve exact terms, and hybrid retrieval combines both to handle meaning plus identifiers, numbers and names.

Why can semantic search perform worse than keyword search?

Exam favouriteEmbeddings may blur exact tokens that matter, such as product SKUs, error codes, proper nouns and numbers. Hybrid retrieval preserves these lexical signals.

Compare Flat, IVF, PQ and HNSW vector indexes.

CompareFlat search is exact but expensive; IVF searches selected clusters; PQ compresses vectors with approximate distance; HNSW navigates a graph for fast approximate nearest-neighbor search.

How does chunk size affect RAG quality?

DesignSmall chunks improve precision but can lose context; large chunks preserve context but dilute retrieval and consume the prompt budget. Choose boundaries, overlap and size for the document and task.

Why use overlapping or parent-document chunks?

DesignOverlap prevents facts at boundaries from being split. Parent-child retrieval searches precise child chunks but returns the larger parent context needed for a complete answer.

Why is re-ranking a second retrieval stage?

Exam favouriteA cross-encoder is more accurate but must jointly process every query-document pair and cannot precompute document representations. Retrieve cheaply first, then re-rank a small shortlist.

What are Recall@k, MRR, faithfulness and answer relevance?

EvaluationRecall@k asks whether a relevant item appears in the top k, MRR rewards an early first relevant item, faithfulness checks support from retrieved context, and answer relevance checks whether the response addresses the query.

What are common RAG failure modes?

DiagnosisMissing context, irrelevant or redundant retrieval, over-retrieval dilution, lost-in-the-middle effects, poor chunking, stale indexes and unsupported generation can all degrade answers.

How is prompt injection through retrieved documents different?

Exam favouriteThe malicious instruction arrives inside data retrieved by the system, not necessarily from the user. Treat retrieved text as untrusted, isolate it from instructions and validate tool actions.

How should a RAG system handle knowledge freshness?

DesignUse full or incremental re-indexing, document versioning, timestamps, deletion handling and time-decay or freshness-aware ranking where the domain changes frequently.
